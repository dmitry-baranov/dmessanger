# dmessanger

Экспериментальный защищённый мессенджер:

- Android-приложение на Flutter;
- backend-монолит для небольшого числа активных пользователей;
- сообщения, фото и видео;
- 1:1 чаты и групповые чаты;
- 1:1 звонки и групповые звонки;
- вход только для заранее созданных пользователей;
- end-to-end encryption для переписки и звонков.
